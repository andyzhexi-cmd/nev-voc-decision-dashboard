# 真实数据接入规范

> 负责模块：`services/data_ingest/importer.py`（纯函数，无 Streamlit 依赖）
> 模板文件：[`samples/comments_template.csv`](samples/comments_template.csv)

## 1. 一句话说明

把八爪鱼采集器、平台导出或手工整理的 CSV / TSV / Excel / JSON，
转换成与仿真数据**完全一致**的标准 schema；先体检、后落盘、可干跑。

## 2. 标准 schema（写入 `data/raw/comments_raw.csv` 的列顺序）

| 列 | 必需 | 含义 | 说明 |
|---|---|---|---|
| `comment_id` | — | 自增主键 | 导入时重排 |
| `platform` | 否 | 来源平台 | 缺失填空，不影响算法 |
| `brand` | 否 | 品牌 | 缺失会影响分组与车型榜，页面会提示 |
| `model` | 否 | 车型 | 同上 |
| `comment_date` | 否 | 发布时间 | 统一格式化为 `YYYY-MM-DD`，解析失败置空并计数告警 |
| `comment_text` | **是** | 评论正文 | 唯一必需列；去空、去 `nan` |
| `_attr_ground_truth` | — | 属性金标准 | 真实数据为空（算法据此跳过与金标准的对照） |
| `_sentiment_ground_truth` | — | 情感金标准 | 真实数据为 0 |

## 3. 列名别名（大小写与空格不敏感）

| 标准列 | 可识别的列名 |
|---|---|
| `comment_text` | 评论、内容、正文、comment、text、content、评论内容、comment_content、body |
| `brand` | 品牌、车系、厂商、brand、car_brand |
| `model` | 车型、车款、车系型号、model、car_model |
| `comment_date` | 时间、日期、发布时间、评论时间、发布日期、date、publish_time、created_at |
| `platform` | 来源、网站、平台、发布平台、source、website、platform、media |

未命中时可在 UI 的列映射下拉里手动指定；仍无法映射到 `comment_text` 则**拒绝导入**并给出可执行提示。

## 4. 编码与分隔符

- 编码嗅探顺序：`utf-8-sig → utf-8 → gb18030 → gbk → big5 → latin-1`（国内平台多为 GBK）
- 分隔符嗅探：`,` `\t` `;` `|`（`csv.Sniffer` + 计数兜底）；`.tsv` 强制制表符
- `.xlsx/.xls` 与 `.json` 直接走对应解析器

## 5. 校验规则

| 级别 | 条件 | 处理 |
|---|---|---|
| 错误（拒绝导入） | 缺少 `comment_text` 映射 | 提示可接受的列名 |
| 错误（拒绝导入） | 出现 object 索引或 `Unnamed:` 列 | 正文逗号/换行未加引号导致**列错位**，提示改用 Excel「CSV UTF-8」或上传 .xlsx |
| 错误（拒绝导入） | >50% 行的正文为空 | 同上，列错位或文件为空 |
| 错误（拒绝导入） | 清洗后 0 条可用评论 | 提示检查源文件 |
| 告警 | 缺 `brand`/`model`/`comment_date`/`platform` | 对应字段置空，说明影响面 |
| 告警 | 存在正文完全相同的行 | 默认**不去重**（计数可见）；勾选"按正文去重"才会删除 |
| 告警 | 时间无法解析 | 计数并置空，不影响算法主链路 |

## 6. 落盘与回滚

- `dry_run=True` 只出报告不落盘（UI 预览用）
- 正式导入原子写入：先写 `comments_raw.csv.tmp` 再 `replace`
- 覆盖前自动备份到 `data/upload_backups/comments_raw_<时间戳>.csv`，同名即回滚点
- 导入成功后 `state.store.bump_data_version()` 失效全部缓存

## 7. 接入后的标准流程

```
导入 CSV/XLSX → 预览体检报告（映射/行数/告警）→ 确认落盘
  → 阶段1 清洗分词 services/preprocess/pipeline.run()
  → 阶段2 属性聚类 services/aspect_mining/run_clustering.main()
  → 阶段3 双模型情感 services/sentiment/run_sentiment.main()
  → data_store 失效缓存 → 视图/报告读取新数据
```

无金标准的真实数据会自动跳过 P/R/F1、纯度等"与金标准对照"的指标，
相关卡片显示"该数据集不含金标准"，不编造数字。
